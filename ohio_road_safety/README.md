# Ohio Road Safety

This project is a standalone research folder for a paper on road safety, housing markets, and local business activity in Ohio.

Working title:
`Road Safety, Housing Capitalization, and Local Business Activity: Evidence from Ohio`

The current baseline design is narrower than the original draft:

- use only road-levy renewals, `description == "R"`
- treat election year as a transition year, not the main treatment year
- focus on lagged post-election outcomes because failed renewals should degrade road quality gradually
- use close renewal failures versus close renewal passes as the causal comparison

## Folder structure

- `code/`: R scripts for inventory, panel construction, renewal-event construction, and model setup
- `data/`: project-local catalogs and derived outputs
- `docs/`: paper design, variable map, empirical strategy, and workplan
- `output/`: tables, figures, and logs generated by this project

## Quick start

1. Run `code/00_make_dirs.R` to ensure the project directories exist.
2. Run `code/01_data_inventory.R` to check that all external input files are available.
3. Run `code/02_build_fars_local_gov_panel.R` to build a crash panel on the harmonized local-government geography.
4. Run `code/03_build_housing_sample.R` to create transaction-level and aggregated housing samples.
5. Run `code/04_build_employment_panel.R` to create annual employment and establishment panels from the geocoded ODJFS masterfile.
6. Run `code/05_build_analysis_panels.R` to merge roads, crashes, housing, and employment into annual analysis files.
7. Run `code/05b_build_renewal_event_panel.R` to create one row per road-renewal election with pre-election and post-election horizons attached.
8. Run `code/06_model_setup.R` to estimate the renewal-only lagged baseline specifications.

## Key project choices

- Preferred geography: harmonized `FIPS_ID`, defined as place GEOID for cities and villages and county-subdivision GEOID for townships.
- Joint analysis window: 2006-2021.
- Preferred election sample: `purpose2 == "roads"` and `description == "R"`.
- Preferred identification sample: close renewal elections, with `close_5` as the baseline bandwidth.
- Preferred timing:
  - crashes: `t+1` to `t+3`
  - housing and employment: `t+2` to `t+4` in the baseline, `t+2` to `t+5` as the longer-run robustness window
- Preferred first-pass design: election-level local-linear RD/reduced form around zero margin, not contemporaneous panel fixed effects.

## Why the design changed

The earlier pooled `A/R` design was too loose for the mechanism you want to defend. Renewals are cleaner because:

- they represent continuation versus expiration of an existing road funding stream
- the timing is easier to interpret than new-authority levies
- the effect should be delayed, not immediate, because road deterioration and traffic risk accumulate

That timing logic also implies:

- election year `t` is mostly pre-treatment in annual data
- crash outcomes should move before house prices and business activity
- averaged post windows are more informative than noisy single-year outcomes
